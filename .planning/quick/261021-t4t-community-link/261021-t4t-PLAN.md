# Quick Plan — Funsmith Club link in the top-right corner (261021-t4t)

**Branch:** `main` (direct, no worktree)
**Baseline:** `4e01a61`, 86 files / 1762 tests green

## Objective

The user asked to "add the discord logo and funsmith club [https://funsmith.club] in the top
right corner." One link, on every screen: the Discord mark beside the words "Funsmith Club",
opening https://funsmith.club in a new tab, pinned to the page's top-right corner.

## Design decisions

1. **One component, cross-game chrome.** `ui/CommunityLink.tsx` renders beside the wordmark in
   `App.tsx` — the shell, because it belongs to no game — and therefore shows in all four modes.
2. **The corner is the page column's, not the viewport's.** `#root` becomes `position: relative`
   so the link stays inside the centred, bordered column at every width. Below the column
   breakpoint the link drops into the flow under the title.
3. **No new colour.** The mark is inline SVG (the Simple Icons Discord glyph, CC0 — inline so
   the static bundle stays self-contained, like the self-hosted fonts) filled with
   `currentColor`; link and glyph brighten together on hover. Brass and lilac stay reserved.
4. **Safe external link:** `target="_blank"` with `rel="noopener noreferrer"`; the SVG `<title>`
   makes the accessible name "Discord Funsmith Club".
