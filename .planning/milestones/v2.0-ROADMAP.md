## What was hardest, and what it taught

- **The 2-deck evaluator was the milestone's real risk.** The stock library silently
  mis-scores duplicate hands rather than crashing — five deuces return "HighCard" — so the
  research had to be empirical, and the fix is a suit-remap proxy validated against a
  brute-force oracle over 300k windows.
- **Reveal didn't recondition.** Phase 6 shipped a hole-card reveal that shrank the sampling
  pool but never *pinned* the revealed card in trials, so the odds barely moved — the phase's
  whole educational payoff. Caught by code review, not by any test.
- **`npx tsc --noEmit` type-checks nothing here.** The root tsconfig is solution-style, so the
  gate passed against deliberately broken code for most of the milestone. `tsc -b` is the real
  gate; two phase verification records carry corrections saying so.
- **Guards must be falsified, not admired.** Several shipped pins turned out to pass
  vacuously — a store-free sweep that missed `blackjackOddsStore`, a width cap that bounded the
  content box while the arithmetic assumed the border box. Both were found by attacking them.
