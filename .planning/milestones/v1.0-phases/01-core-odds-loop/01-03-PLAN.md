Library import constraint (verified): `@poker-apprentice/hand-evaluator` is published as CJS with an ESM build and no `exports` map. Named ESM imports throw. Library comparator convention (verified empirically): the raw `compare(a, b)` returns `-1` when `a` is the STRONGER hand and `+1` when `a` is WEAKER. It is a sort-strongest-first comparator, the reverse of naive numeric intuition.
