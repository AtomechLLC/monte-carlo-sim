## Phase Goal

**As a** poker learner testing a specific idea, **I want to** place exact cards into my hole and the board before dealing, **so that** I can construct the "what-if" scenario I care about instead of waiting for it to come up at random.

<objective>
Deliver manual scenario construction (DEAL-02) with an observable duplicate block (DEAL-03): a seven-slot picker whose draft merges into the existing single Deal flow (D-03), never a second "construct mode".

Purpose: This is the other half of "probability made visible" — being able to set the exact hand you want to reason about, and seeing the deck shrink as you do it.

Output: `pickerStore` with duplicate-rejecting draft slots, a merge-on-deal `gameStore.deal()` that draws all random fill from one shuffle, and a `CardPicker` component with a native `<dialog>` 52-card panel.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Picker click → pickerStore | Values come from a closed 52-item enumeration of the `Card` union; no free text, no injection surface. |
| pickerStore draft → gameStore.deal | Draft cards become simulation inputs; a duplicate here would corrupt every probability downstream. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-15 | Tampering | Duplicate card entering a runout via the draft | mitigate | Two independent controls: `setPick` rejects a card already held by another slot, and `deal()` draws random fill from `deckWithout(pickedCards(picks))` in a single no-replacement shuffle. A 200-iteration test asserts 13 distinct cards per deal. |
| T-02-16 | Input validation | Picker input surface | accept | The picker emits only members of the closed `Card` union from a fixed 52-button panel; there is no free-text path, so this is a business-rule invariant rather than a security control (ASVS V5, per `02-RESEARCH.md` Security Domain). |
| T-02-17 | Denial of service | Native `<dialog>` focus/Escape behaviour suppressed | accept | Mitigated by construction — no custom focus trap or `cancel` interception is added; an acceptance grep asserts `preventDefault` is absent. |
| T-02-SC | Tampering | npm installs | accept | No packages added — the picker is built from `ALL_SUITS`/`ALL_RANKS` already present in `@poker-apprentice/types` (`02-RESEARCH.md` Don't Hand-Roll). If a combobox/dialog library seems necessary, stop and escalate rather than installing. |
