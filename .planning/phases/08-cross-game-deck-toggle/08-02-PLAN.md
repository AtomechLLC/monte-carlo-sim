**As a** probability explorer using the simulator, **I want to** change the deck count from the same control in both Hold'em and Blackjack, always showing the active game's current shoe, **so that** switching shoes is one consistent gesture that immediately recomputes the odds with no stale numbers left behind.

This is the first suite that asserts it as ONE cross-game contract exercised through ONE control.
