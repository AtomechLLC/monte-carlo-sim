**As a** probability explorer using the simulator, **I want to** change the deck count from the same control in both Hold'em and Blackjack, always showing the active game's current shoe, **so that** switching shoes is one consistent gesture that immediately recomputes the odds with no stale numbers left behind.

<objective>
Extract the two shipped inline deck toggles into ONE shared component and rewire both games onto it, changing no rendered byte.

Purpose: this is the whole of SC1 and the entire source diff of Phase 8. The phase is a behavior-preserving consolidation, so the interesting engineering is not the component — it is the PROOF that nothing moved. The shared component (emit this shape; attribute ORDER is load-bearing for the D-06 byte-identity
golden — it matches both originals exactly):

```tsx
import type { DeckCount } from '../engine/shoe';

interface DeckCountToggleProps {
  testidPrefix: string;
  deckCount: DeckCount;
  onSelect: (deckCount: DeckCount) => void;
  oneDeckDisabled?: boolean;
  oneDeckTitle?: string;
  twoDecksTitle?: string;
}

export function DeckCountToggle({ ... }: DeckCountToggleProps) {
  return (
    <div data-testid={testidPrefix} role="group" aria-label="Deck count">
      <button
        type="button"
        data-testid={`${testidPrefix}-1`}
        aria-pressed={deckCount === 1}
        disabled={oneDeckDisabled}
        title={oneDeckTitle}
        onClick={() => onSelect(1)}
      >
        1 deck
      </button>
      <button
        type="button"
        data-testid={`${testidPrefix}-2`}
        aria-pressed={deckCount === 2}
        title={twoDecksTitle}
        onClick={() => onSelect(2)}
      >
        2 decks
      </button>
    </div>
  );
}
```
