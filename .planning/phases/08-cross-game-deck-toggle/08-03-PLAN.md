## Phase Goal

**As a** probability explorer using the simulator, **I want to** change the deck count from the same control in both Hold'em and Blackjack, always showing the active game's current shoe, **so that** switching shoes is one consistent gesture that immediately recomputes the odds with no stale numbers left behind.

<objective>
Close Phase 8 and the v2.0 milestone's last phase: prove the consolidation changed nothing, reconcile every source item, and take acceptance in a real browser.

Purpose: this phase's entire claim is a negative one — "the shared component behaves identically to the two it replaced." A negative claim needs a gate that looks for the change rather than for the feature. This plan runs the mechanical half (byte-untouched CSS, byte-untouched goldens, zero pre-existing test edits, per-commit guard health, the golden's commit ordering) and the half no jsdom suite can reach: two real games in a real browser, on a production bundle, where the disabled dimming and the segmented-control treatment are actually rendered.
Output: no source changes. A regression record, a blocker reconciliation, a coverage audit and a verdict.
</objective>
