## Phase Goal

**As a** probability explorer using the simulator, **I want to** play Hold'em over a 104-card two-deck shoe — with duplicate-card hands evaluated correctly, a Five of a Kind row in the odds table, and a visible cue on the second copy of any card on the felt — **so that** I can see exactly how deck composition changes what hands are possible and how likely they are.

<objective>
Give Hold'em a deck count and make every physical-card path honour it: the shoe `deal()` draws from, the picker's blocking and labels, and the toggle's lifecycle semantics — all at the store and component level, with no UI control yet.

Purpose: this is the HE2-01 substrate. Phase 4 already built count-aware `shoeWithout`, `remainingCopies` and `setPick`; every one of them is still wired to a hardcoded 1. This plan turns those wires live and closes WR-01 (the pinned `const deckCount: DeckCount = 1` in `CardPicker.tsx`, whose own comment documents the silent-lost-picks trap) a phase early, exactly as D-15 authorises.
Output: a `deckCount`-aware `gameStore`, an additive count-aware predicate on `pickerStore`, and a `CardPicker` that reads the live value — plus behavioral tests at both deck counts.

**Planner decisions taken under Claude's Discretion, recorded here for audit:**
- `hasDuplicatePick` is added to `pickerStore.ts` rather than computed inline in a component. UI-SPEC A4 needs the predicate in the UI (to disable the `1 deck` segment, plan 07-05) and `setDeckCount` needs the same predicate as the correctness backstop; a second hand-rolled duplicate count in a component is exactly the value-collapse hazard `shoePath.guard.test.ts` exists to prevent. 07-CONTEXT permits touching `pickerStore` when the D-07 picker work requires it — this is that case, and the change is purely additive.
- This plan carries NO trial-path exposure. `deckCount` defaults to 1, nothing outside tests sets it to 2, and `HoldemGame` does not pass it into `deriveConditionedState` until plan 07-05 lands together with the guard retarget. WR-03 stays respected across this plan's whole commit range.
</objective>
