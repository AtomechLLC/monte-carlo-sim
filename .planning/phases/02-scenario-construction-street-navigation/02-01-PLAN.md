<objective>
Generalize the Phase 1 simulation pipeline from a single fixed knowledge shape (0 known board cards, 0 revealed opponents, always 11 unknown cards per trial) to a variable knowledge partition, and lock the D-02 rule — odds condition ONLY on cards the user can currently see — into a single guardrail function.

Purpose: Every Phase 2 capability (street advance/rewind, opponent reveal, manual scenario construction) is a different knowledge partition over the same predetermined hand. Without this generalization the worker throws on every non-preflop request (Pitfall 2) and the odds silently peek at hidden cards (Pitfall 1). This plan is the contract layer that plans 02-02 through 02-05 build on.

Output: `src/engine/streets.ts`, `src/engine/conditioning.ts` (+ tests), a generalized `ConditionedState`/`runTrials`, a generalized worker contract with dynamic validation and a per-invocation run token (WR-01, worker side), and a `ConditionedState`-based `simulationService` with error surfacing and Comlink proxy release (WR-02, IN-08).
</objective>

<mvp_note>
This plan carries no new user-visible capability on its own — it is the contract half of the street-navigation slice, split from `02-02-PLAN.md` purely on context cost (the full slice spans 17 files across engine, worker, state and UI; one plan cannot hold it within budget). `02-02-PLAN.md` completes the slice in wave 2 and is the first plan a user can see the effect of. The existing Phase 1 end-to-end path (Deal -> streaming odds) keeps working through this plan; only the shape of the arguments changes.
</mvp_note>
