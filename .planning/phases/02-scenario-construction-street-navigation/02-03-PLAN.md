## Phase Goal

**As a** poker learner, **I want to** rewind to any street I have already seen and reveal an opponent's cards at will, **so that** I can watch exactly how each new piece of information reshapes the numbers instead of guessing at it.

<objective>
Make knowledge changes first-class: cache settled odds per knowledge state so rewinding literally returns to earlier-street values (D-10, NAV-02), and add one-way opponent reveal that changes the knowledge state for every street at once (D-08/D-09/D-11, NAV-03).

Purpose: This closes the educational payoff of the phase — after a reveal, rewinding shows earlier streets' odds *changing* relative to what they were pre-reveal, which is the whole point of the feature.

Output: A knowledge-keyed settled-odds cache in `oddsStore`, `reveal()` on `gameStore`, clickable opponent seats in `HandDisplay`, and an `App` effect that consults the cache before ever touching the worker.
</objective>

|----------|-------------|
| User click (seat / nav) → Zustand store | Enumerated actions with an integer opponent index bounded by the rendered seat count. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-11 | Tampering | Cached snapshot served for the wrong knowledge state | mitigate | Composite key `${street}|${revealedMask}` plus `clearCache()` on every `deal()`; integration tests assert no cross-hand and no cross-mask hits. |
| T-02-12 | Information disclosure | Seat markup exposing an unrevealed opponent's cards in the DOM | mitigate | Hidden seats render the literal string `Hidden`; card codes are only read from `runout.opponentHoles[i]` inside the `isOpponentRevealed` branch. |
| T-02-13 | Denial of service | Unbounded cache growth | accept | At most 4 streets x 8 reveal masks = 32 entries per hand, and the map is cleared on every deal. |
| T-02-14 | Repudiation | — | accept | No accounts, no persistence, no audit requirement. |
| T-02-SC | Tampering | npm installs | accept | No packages added; if an install appears necessary, stop and escalate. |
