## Phase Goal

**As a** poker learner, **I want to** watch the cards actually be dealt to the table before the numbers move, **so that** I always learn what the odds are for a hand I can already see, never for a card the app has not shown me yet.

<objective>
Install Motion, deal the eight hole cards with a staggered fly-in from the deck (TBL-03), and make TBL-04's "odds never spoil a card in flight" invariant structural by gating the odds effect on an animation counter (D-11).

Purpose: the deal choreography is the product feel, and the gate is the correctness claim underneath it. Both belong in one slice because either alone is wrong — animation without the gate spoils cards, the gate without animation gates nothing.

Output: `motion@13.1.1`, a `uiStore` animation counter armed by the four navigation actions, an `AnimatedCard` primitive, a dealt-card choreography, and an `App` odds effect that will not run — on either branch — while cards are moving.
</objective>
