## Phase Goal

**As a** poker learner, **I want to** see real playing-card faces for my hand and the board, **so that** the hand I am reasoning about looks like cards on a table instead of a spreadsheet of two-letter codes.

<objective>
Replace every text card code in the running app with detailed vector card art (TBL-02), delivered as repo-committed CC0 SVG assets behind one mapping component.

Purpose: this is the first slice a user can actually see. After this plan the existing Phase 1-2 layout is unchanged, but dealing a hand shows real cards — pips, court-card art, and face-down backs for hidden opponents.

Output: `public/cards/` (52 faces + one back + a provenance/LICENSE file), `PlayingCard`/`CardBack` components, and `HandDisplay`/`BoardDisplay` rendering through them with every Phase 1-2 testid intact.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | Vendored SVG files from `letele/playing-cards` | mitigate | Download pinned to a resolved commit SHA (not a moving branch) recorded in `public/cards/LICENSE`; `curl -f` so HTTP errors cannot be written into `.svg` files; every file scanned for `<script`, inline `on*=` handlers and absolute `http(s)://` references before commit (acceptance criteria, Task 1). |
| T-03-02 | Elevation of Privilege | SVG rendering path in `PlayingCard`/`CardBack` | mitigate | Art is referenced via `<img src>` only — the browser treats SVG-as-image as a script-free, sandboxed context. `dangerouslySetInnerHTML` is asserted absent in both components. |
| T-03-03 | Spoofing | Asset URL construction | mitigate | Paths are built only from the closed `Card` string union via exhaustive `Record` maps; no free-text ever reaches `cardAssetPath` (RESEARCH Security Domain, ASVS V5). |
| T-03-04 | Denial of Service | Runtime dependency on an upstream repo | mitigate | D-01 vendoring: assets are committed, so upstream disappearing or changing cannot affect the shipped app. Asserted by `grep` for any `raw.githubusercontent` reference in `src/`. |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | This plan installs no packages. `motion` is the phase's only npm addition and is gated in plan 03-03 (slopcheck `[OK]`, no postinstall — 03-RESEARCH Package Legitimacy Audit). |
</threat_model>
