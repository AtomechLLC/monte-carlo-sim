## Phase Goal

**As a** probability explorer using the simulator, **I want to** play a full Blackjack round on its own table — deal, watch bust / dealer-outcome / EV odds converge live, hit or stand, reveal the hole card, and switch the shoe between 1 and 2 decks — **so that** I can see exactly how each new piece of information and each extra deck reshapes the numbers.

<objective>
Build the Blackjack odds cluster: the bust/trials stat row, the Stand win/push/loss group, the two per-unit EV tiles, and the 7-bucket dealer final-outcome table.

Purpose: this is what BJ-03 and BJ-04 are actually asking for, and the dealer-distribution table is the phase's stated educational centrepiece — the display that visibly reshapes when the upcard changes or the hole is revealed. Building it as pure store-driven presentation, in its own plan, keeps it out of the felt plan's much larger diff.
Output: three components, one formatter, one label constant, and a component test suite.

**Planner decisions taken under Claude's Discretion, recorded for audit:**

    - Negative EV -> `'−0.18 units'` using the TYPOGRAPHIC minus U+2212, not the ASCII hyphen.
    - Exactly zero EV -> `'0.00 units'` — unsigned.
    - A value that ROUNDS to zero from either side (e.g. win 501 / lose 500 over 200000 trials) -> `'0.00 units'`, unsigned. A rendered `−0.00` or `+0.00` is a bug.
    - Pushes contribute zero: `{ win: 1, push: 98, lose: 1 }` over 100 trials -> `'0.00 units'`.
    - `{ win: 100, push: 0, lose: 0 }` over 100 -> `'+1.00 units'`; `{ win: 0, push: 0, lose: 100 }` -> `'−1.00 units'`.
  </behavior>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| streamed snapshot -> displayed number | A malformed or short snapshot must not be able to shrink or mislabel the table. |
| animation gate -> displayed number | While cards are in flight, no number may be shown — the pending display always wins over store values. |
| pending deck selection -> displayed subtitle | The subtitle must describe the run the numbers came from, not a selection that has not started a run. |
| blackjack panel -> Hold'em stores | No read, no shared cache key. |
