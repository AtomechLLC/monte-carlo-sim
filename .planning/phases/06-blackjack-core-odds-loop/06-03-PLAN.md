## Phase Goal

**As a** probability explorer using the simulator, **I want to** play a full Blackjack round on its own table — deal, watch bust / dealer-outcome / EV odds converge live, hit or stand, reveal the hole card, and switch the shoe between 1 and 2 decks — **so that** I can see exactly how each new piece of information and each extra deck reshapes the numbers.

<objective>
Give Blackjack a streaming worker path: a second `createStreamingRunner` config, a namespaced Comlink surface, WR-02's deckCount validation on both game APIs, and a main-thread transport that shares one worker with Hold'em.

Purpose: this is the plan that touches shipped Hold'em transport code, so it carries the phase's regression risk outside of 06-02. Isolating it means the golden parity tests are the single, unambiguous gate on "the poker path's external behavior did not change" (D-08).
Output: one worker config, one namespaced worker entry, a validated deckCount boundary on both APIs, and a three-file main-thread transport split.

**Planner decisions taken under Claude's Discretion (06-RESEARCH Open Question 2 explicitly grants the file-layout choice), recorded for audit:**
- **Three-file transport split** (`workerClient.ts` + `simulationService.ts` + `blackjackSimulationService.ts`), following ARCHITECTURE.md. Chosen over "one file with two function pairs" because seven existing test files mock `./state/simulationService` with an explicit two-export factory; adding blackjack exports to that module would make every one of those mocks throw at import time on a missing named export. A separate module leaves all seven untouched.
- **No second cancellation call site on mode switch.** 06-RESEARCH suggests cancelling both games on every mode switch as a cheap idempotent extra. This plan deliberately does not: each game root's odds-effect cleanup already cancels its own run on unmount, and the mode-shell guard pins single-call-site cancellation ownership per game (D-07). Adding a shell-level call would make the guard red for a race the unmount path already closes. Recorded so it reads as a decision, not an omission.
</objective>
